## 接口采集原型验证

2026-10-28 的接口原型在 Windows x64 上执行以下检查；仅记录方法与结论，不附个人接口清单、网络名称或原始用量记录。

Release 构建零告警/零错误，47 个自动化测试全部通过，格式检查和环境诊断通过；本地依赖框架发布及窗口启动通过。

- 原生 GetIfTable2 枚举成功，可区分硬件、过滤、回环、隧道和虚拟/其他条目。分类使用类型和系统标志，默认选择在线硬件候选；不自动识别互联网出口或合计所有接口。
- 三轮各五秒的 `--verify-counters 5` 均观测到硬件正向字节变化，原生计数和差分均落在两端 .NET GetIPStatistics 夹取的上下界内，未发现超界。未注入可控负载，存在自然背景流量；两者共享 OS 计数来源，仅验证结构布局、取值及同层差分的一致性，未完成 1% 的完整精度验收。
- `--sample 3` 能产生有效测量和独立接口内存累计；离线接口保持无测量状态。CLI 不输出名称、稳定标识或绝对启动前计数。
- 按需 Wi-Fi 能力探测返回 Available；权限拒绝、未连接、服务不可用及非 UTF-8 SSID 展示由合成测试覆盖。没有改变本机位置权限，没有验证真实拒绝授权流程或不同 WLAN 切换。
- 窗口实测显示真实收发速度、本次用量和断档状态；应用、远程连接及网络账本仍显示规划状态。界面只显示所选接口，不生成跨层总量。

离线/重连、移除/重现、API 失败、电源通知后重新基线、超过五秒的间隔、双向计数回退、纪元/连接身份变化、时钟回退/前跳及接口隔离由确定性测试验证。它们不等价于实际断网、禁用网卡或真实睡眠恢复验收；这些会影响当前桌面连接，本轮未执行。轮询间完成的短暂切换或未改变可见字段的复位仍可能无法识别。

接口阶段之后补齐的 WLAN 通知和边界分区见下一节；真实切换、多出口路径、不同权限/会话、可控负载与吞吐/资源基线及长时间稳定性仍待验收。

## Wi-Fi 候选分账原型验证

同日完成第二阶段，按用户选择仅执行代码、合成事件和无需断网的实机检查，没有执行断开/切换网络、位置权限更改、禁用网卡或睡眠操作。公开记录仅保留方法与结论，不保存接口、网络、配置、BSSID、路由地址或实际字节明细。

- Release 构建零告警/零错误，80 项自动化测试通过，格式检查、原接口采样、同层计数参考、环境诊断及新命令非法时长退出码均通过。新增测试涵盖同名网络不同上下文、原始 SSID/配置/安全类型、往返切换、AP 漫游不按 BSSID 拆键、两次轮询间断开又返回、查询期间通知/上下文/接入点变化、权限失败、通知降级、暂停/恢复及守恒。
- 三轮各五秒 `--watch-wifi 5` 在当前稳定连接下成功注册 ACM/MSM（Coverage=Full），连接查询可用，无计数读取失败；每轮候选+边界+未知的两个方向均与有效观察总量精确相等。存在自然背景流量，没有注入可控吞吐负载。Full 是订阅源状态，不是事件送达零丢失证明。
- 本机 Windows SDK 的 C++ static_assert 编译成功，独立核对 MIB_IF_ROW2、WLAN_CONNECTION_ATTRIBUTES、WLAN_NOTIFICATION_DATA 和 MIB_IPFORWARD_ROW2/TABLE2 的互操作大小/偏移。验证文件仅位于忽略的本地构建目录，不是项目编译依赖。
- `--route-summary` 原生读取成功，能返回硬件、虚拟和回环接口的默认/其他前缀路由摘要。不含网关和目的地址，不将默认路由数量或前缀数量解释为应用出口。
- 桌面可进入网络账本并明确启用，显示实际候选字节和独立的边界/未知记录。界面模型的暂停释放、恢复排除停采期、等待在途读取后退出、电源通知丢弃旧读取由异步回归测试覆盖；原生监听器的注册/释放通过三轮有界命令实测。完整界面启停/退出交互未单独验收，没有把稳定连接测试记为真实切换或睡眠验收。

合成回放不证明通知在所有设备、权限、会话和漫游情况下及时送达。相同候选可能混同、上下文变化可能拆分，人工校正未实现；本轮已保存候选历史，但不使 V1-02/V1-03 自动完整通过。

## 应用 ETW 原型验证

同日新增明确启用的应用原型和回环覆盖命令，仍遵守无需断网约束，没有切换网络、睡眠或改变系统权限。当前执行令牌不是管理员，没有触发 UAC；因此不声称真实内核采集通过。

- Release 构建零告警/零错误；111 项测试通过，包括全部既有 80 项。新增验证四种传输双向整数守恒、零/缺失、短生命周期、PID 复用、缺失 Stop、rundown 不追记、错键 Stop、容量溢出降级、乱序/丢失撤回归属、原生元数据版本/长度和 UINT32 size。
- 假会话直接注入实际 Windows 采集器，验证停止幂等、等待消费者排空后释放、最终可见丢失合并、健康查询失败、停止失败中断和消费者异常。桌面模型验证权限提示、停后保留/重启替换、在途读取/启动期间关闭、电源停止和读取异常清理。这些都没有启动特权原生会话。
- 本机普通权限真实运行 `--watch-apps 1` 和 `--verify-apps`，均退出 1、State=AccessDenied、Observed=null，未生成回环探测流量或触发提升；非法时长 0/61/invalid 均退出 2。原接口采样、同层参考和路由摘要回归通过。
- 新版窗口可启动，目视检查应用页初始布局、开始/停止按钮和无数据提示。完整原生应用采集启停、权限提示交互和管理员运行未单独验收；未把窗口打开当作 ETW 采集成功。
- 管理员实际 TCP/UDP v4/v6、真实短连接/进程复用、QUIC、外网/代理路径、独立同层误差、吞吐/CPU/内存及长时间稳定性均待验证；本轮未把它们标为通过。`--verify-apps` 即使未来返回 0，也只证明受控回环覆盖/归属，不能替代 size 精度验收。

细节和下一轮方法见 [ADR 0003](decisions/0003-application-etw-validation.md)。以上为 2026-10-28 历史结果，后续管理员验证见下一节。V1-04/V1-05 保留未完成状态。

用户手动确认管理员桌面的开始采集、停止后保留记录。自动化无法可靠操作该提升窗口，故这条结论明确来自用户操作；没有声称完整 GUI 关闭/重启/电源流程实机通过。桌面快捷方式已更新到修复版。

## 真实采集矩阵

2026-10-29 后续已完成本机 QUIC、三轮持续 TCP、异常会话恢复，以及当前 Clash / 隔离 Mihomo 的显式代理关联。自动化回归增至 171 项。下表仍是完整目标矩阵，不代表各项均通过；结论与限制见[本轮报告](validation/2026-10-29-reliability-proxy.md)和[支持矩阵](support-matrix.md)。

| 场景 | 验收重点 |
|---|---|
| 直连 TCP IPv4/IPv6 | 进程、服务器、收发方向与同层参考字节 |
| UDP/QUIC | 不因只实现 TCP 而遗漏；无法归属可见 |
| 本机系统代理 | 原应用/代理两段分别识别；网络账本不叠加回环 |
| TUN | 隧道内层与物理外层分开；不重复累计 |
| 同时直连/代理 | 按已确认连接路径展示，不整机一概标为代理 |
| 不同 WLAN 切换 | 不串网络；切换边界不确定量单列 |
| 同名 WLAN / 漫游 | 可区分不同网络；同网 AP 漫游不默认拆账 |
| SSID 权限拒绝 | 接口级可降级，不能沿用旧 SSID |
| 有线/WLAN 多出口和 VPN 分流 | 不依据单一路由猜测；过滤层条目不重复相加 |
| 虚拟机传输 | 明确宿主可见边界，不声称看到来宾内部应用 |
| Xshell / OpenSSH 多会话及非 22 端口 | 进程与连接关联、服务器别名 |
| SSH 经代理、跳板、连接复用或端口转发 | 显示可确认隧道边界，不猜测内部业务 |
| 远端自身下载 vs SCP/SFTP 到本地 | 只计经过本机的数据 |
| 短连接、高并发及高吞吐 | 不依赖活跃连接快照承担全部计量；监测丢失 |
| 核心重启、网卡复位、休眠和重启 | 新基线、无负数/突增、断档可见 |
| PID 复用 | 不与旧进程历史串账 |
| 跨日/月、时区与系统时间变更 | 账期清晰，明细与聚合逐字节一致 |
| ETW 丢失、API 断连及权限失败 | 显示时间与影响范围，不能假装完整 |
| 界面关闭、重新登录、异常退出 | 后台行为符合设计；数据库可恢复且不重复写入 |

## 初始质量目标

这些是待验证的目标，不是当前性能承诺。

- 使用可控数据源及同层独立参考，至少重复三次，注明背景流量和系统环境。文件大小不能作为物理接口字节真值。
- 正确物理接口同区间的累计账本与参考计数差异目标不超过 1%；单独报告切换未分配量。这不等于与 ISP 账单的误差保证。
- 无 ETW 丢失、可确认归属的应用场景，与同层参考差异目标不超过 3%；重传、封装和卸载差异另说明。
- 代理关联须有证据；未知归属保留，按客户端/核心版本报告覆盖范围。
- 同一统计口径的时间桶、日报/月报和导出精确一致；只允许显示单位舍入差异。
- 72 小时运行无持续内存增长、重复批次或未标记的故障，异常退出后可恢复。
- 初步资源预算：空闲总 CPU 平均低于 1%，常规工作集低于 200 MiB；高吞吐另报告吞吐量、CPU、内存、ETW 丢失及统一的 CPU 百分比口径。
