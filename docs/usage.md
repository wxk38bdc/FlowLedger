# 使用 FlowLedger

当前为 v0.2 开发预览，支持简体中文和 English。右上角切换语言；下次启动沿用选择。

## 开始记录

打开程序后，**总览**自动采集接口计数，选择你要观察的接口。接口各自独立，物理候选不等于已确认的互联网出口。速度或用量显示“尚未测量”意味着还没有有效观察。

**网络账本**需点击“启用 Wi-Fi 分账”。系统可能提示位置权限。稳定候选、边界未分配和未识别网络分别保留，网络切换实机验收仍待完成。

**应用统计**需以管理员身份打开程序，再点击“开始应用统计”。同名应用的不同进程实例分行展示，历史报表按应用名汇总。

**代理账本**填写本机 HTTP/mixed 入口端口，点击“查找本机控制器”，在本地密钥框输入控制器密钥，再点击“启用代理观察”。密钥只在内存中使用，不保存在 SQLite。核心总量和部分连接增量分别展示。真实 TUN 验证已暂缓。

## SSH 连接

1. 以管理员身份打开 FlowLedger，进入 **SSH 连接**，点击“开始 SSH 统计”。
2. 用 Windows 终端里的 OpenSSH 新建连接，例如正常运行你自己的 `ssh` 命令。程序不读取命令行、配置或密钥。
3. 查看可见远端、客户端/PID/本地端口、接收与发送量。悬停服务器栏可查看结束状态；每个连接实例单独保留。
4. 已经存在的非标准端口连接，先停止统计，在“服务器别名与规则”添加准确 IP、端口和别名，再开始。规则也用于给常用服务器命名。

IPv4 / IPv6 和自定义端口可用；规则使用实际 IP，不自动解析主机名。`ssh.exe` 等名字只标为“客户端候选”；“用户规则”表示你确认了用途，均不代表软件解密或验证了协议。Xshell/PuTTY/Plink 的名称规则已实现，但本轮优先实测 OpenSSH。

跳板机、代理和隧道只展示本机可见连接，不猜测最终服务器。端口转发可能产生额外 TCP 腿，不将候选总量称为唯一 SSH 加密流量。远端自己下载的文件不会直接全部记成本地下载，终端输出/传输仍会计入本地收发。复用连接无法拆成每个终端通道。

停止后保留本页记录；再次开始建立新会话，本页替换为新记录，已经保存的历史仍可查。电源边界停止应用、代理和 SSH 采集，需要手动重新启用。

## 历史与报表

已观察的数据正常每 5 秒合批自动保存，停止、查询和退出时立即排空，保存到：

```text
%LOCALAPPDATA%\FlowLedger\history.sqlite3
```

进入 **历史报表**，刷新账本列表，选择一个独立账本、汇总周期、起止日期和时区，再查询。结束日期包含当天；周从周一开始。可导出当前查询为 CSV。查看“部分”行标记和质量提示，空白不是零用量。

报表按采样观察结束时间归账，跨账期区间不按比例拆分。只能查询已保存的观察；软件关闭期间不采集。历史不会因为停止采集、更换会话或重新启动软件而清空。窗口底部显示保存状态；存储失败会重试，退出时仍有未保存记录会提示。

数据库含本机网络名和 SSH 服务器地址等个人使用记录，仅保存在本机，未加密；控制器密钥、SSH 密钥/密码、命令行和报文内容不保存。CSV 当前会导出真实名称，分享前自行检查。暂未提供自动清理、备份恢复或后台服务。

关闭程序后再备份整个 `%LOCALAPPDATA%\FlowLedger` 目录；若仍有 `history.sqlite3-wal`/`-shm`，一并保留，不要在运行时只复制主数据库文件。升级时保留此目录。开发构建和旧验证窗口应先关闭，再启动新版快捷方式。

完整实现与验收边界见[支持矩阵](support-matrix.md)和[存储与 SSH 决策](decisions/0005-local-history-ssh-reports.md)。
