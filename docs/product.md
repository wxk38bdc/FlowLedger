# 产品范围

FlowLedger（流量簿）回答三个问题：在什么网络上用了多少流量，哪些应用产生了流量，哪些代理或 SSH 连接承载了这些流量。

## 第一版目标

| 维度 | 目标 | 限制 |
|---|---|---|
| 网络 | 不同 Wi-Fi、热点、有线网络分账；可设置别名 | 同名网络、AP 漫游和无法读取 SSID 的情况需要单独处理 |
| 应用 | 上传/下载、实时速度、周期排名、多进程合并 | 无法确认归属时单列未知；不根据应用名称猜测 |
| 代理 | 旧 Clash / Mihomo 的链路增强和重复统计处理 | 系统代理与 TUN 分别验证；不同核心字段和能力可能不同 |
| SSH | Xshell / OpenSSH 按连接、服务器统计本地消耗 | 跳板、复用和隧道内部业务可能无法细分 |
| 时间 | 日、周、月、自定义区间和账期 | 明确时区、周起始日、跨日和断档 |
| 数据 | 本地历史库、CSV、额度提醒 | 默认不上传使用历史；导出应提供隐藏网络/服务器名称的选择 |

## 当前可运行内容

桌面提供实时独立接口采样、按需 Wi-Fi 候选分账及路由摘要，以及需要管理员权限的实验性应用统计页面。应用原型消费 TCP/UDP、IPv4/IPv6 事件，按进程实例保留收发 size 和未知桶；三轮管理员受控回环归属/字节及短连接、并发突发实测通过，完整覆盖/精度及持续性能仍待验收。命令行支持匿名诊断、接口参考核对、Wi-Fi 观察、应用观察和本机回环交叉验证入口。记录仅在内存中，关闭丢失；代理/SSH、后台服务、持久历史及日周月报表待开发。

## 首版之外

跨平台、云同步、服务器端代理、企业集中管理、限速防火墙、包内容分析及逐条 SSH 命令计量不属于首版范围。不会为了统计而要求解密用户的 HTTPS 或 SSH 内容。

## 页面规划

- 总览：当前网络、上传/下载、趋势、额度与记录完整性。
- 网络账本：按网络/账期查询，展示连接时段和切换未分配量。
- 应用统计：应用排名、历史、进程聚合与已确认代理路径。
- 远程连接：服务器别名、会话、SSH/代理路径及隧道边界。
- 运行环境及后续设置：权限、采集状态、数据保留和适配器状态。

界面必须让用户区分“无数据”“实际为零”“部分缺失”和“无法归属”。不能用示例数据伪装已采集结果。
