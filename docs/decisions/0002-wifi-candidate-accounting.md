# ADR 0002：Wi-Fi 候选身份与边界分区

状态：采集验证原型，2026-10-28。

## 问题

接口计数与连接查询不是一个原子快照。两次采样之间可能切到另一个网络又返回，查询期间也可能发生漫游。SSID 同名不证明同一网络，BSSID 改变也不必然意味着不同网络。网络变化时直接清除接口计数基线，会丢掉原本可以测得、但无法精确归属的边界字节。

## 决定

将接口计数连续性与网络身份分开：设备 LUID/索引及计数纪元保护接口基线；NetworkGuid 与原始 SSID、配置和安全类型构成逐接口的网络候选键。候选键不含 BSSID。缺少上下文时保持未知，字段相同的不同实际网络仍承认歧义，不声称全球唯一或自动发现一切同名网络。

明确启用后才订阅 ACM/MSM 并持续查询连接。先记录通知序列并查询连接，再读取接口计数，之后再次查询连接并记录序列。两端不稳定、版本变化或候选/接入点变化使区间整体进入边界未分配；身份缺失或通知降级进入未识别网络。只有稳定、同版本且身份一致的相邻观察才归属候选。计数本身无效时保持断档，没有字节可分配。

启用首样本和恢复首样本只建立归属基线。每个接口的候选、边界、未识别之和必须逐字节等于纳入本次分账的有效字节。没有跨接口或层级合计，没有补齐停采期的估算，也没有持久化。

## 限制与验证

通知到达有时序和送达不确定性，订阅成功不等于零丢失证明。延迟/遗漏且未改变可见身份的切换可能仍无法识别。查询结果仅代表实际观察到的时段，不是已通过完整硬件验收的运营商账单。

本轮完成合成事件回放、查询竞态、守恒和无需断网的真实稳定连接采样。真实不同热点、同名网络、跨 AP 漫游和睡眠恢复按硬件验收矩阵另测；应用出口不能从单个默认路由推出。未来持久事实存储应保留候选键版本、观察范围、未知/边界与断档，使人工合并/拆分可审计。
