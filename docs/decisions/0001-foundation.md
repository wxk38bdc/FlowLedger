# ADR-0001：Windows 原生桌面与分层采集基础

日期：2026-10-28。状态：接受基础选型；采集技术仍受 V1 验证约束。

## 背景

产品需要 Windows 应用归属、Wi-Fi 切换、代理和 SSH 计量。主要风险来自不同网络栈层级的重复观测、权限和未知归属。第一阶段应建立可验证的开发基础，不先承诺任意代理下的精确细分。

## 决策

- 使用 .NET 10 / C#，WPF 为初始桌面框架，首批运行目标为受支持的 Windows x64 环境。
- Domain 与平台无关；Application 定义契约；Windows 适配器实现系统查询；桌面与采集入口分别组成应用。
- 当前仅实现基础计数规则和匿名化只读诊断。采集入口为普通控制台程序，服务化在后续进行。
- 候选数据源是系统接口计数、ETW、Native Wi-Fi 和版本适配的代理只读 API；先验证，不直接引入驱动依赖。
- SQLite 与本机 IPC 保留为明确的后续设计，不提前提供没有行为的存储/服务实现。
- 用 MSTest 的现代测试平台验证记账边界；固定测试 SDK 版本。CI 在 Windows 执行构建、测试、格式和诊断。
- 沿用仓库已有 Apache-2.0 许可证。

## 后果与重新评估条件

WPF 将桌面限制在 Windows，符合首版范围。权限、SSID、事件层级与准确度仍需真实测试，基础项目可编译不能替代采集验证。如果 ETW 的完整性、性能或归属达不到核心门槛，重新评估 WFP 等方案，并记录签名、部署与维护成本；若新增平台需求，再评估 UI 和适配器选择。

未来依赖和真实功能进入仓库时，补充验证依据及本决策的变更记录。
