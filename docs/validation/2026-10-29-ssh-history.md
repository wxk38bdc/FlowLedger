# SSH、本地历史与双语报表验证

日期：2026-10-29，Asia/Shanghai。所有网络探测只连接本机临时 loopback 端点；不读取用户 SSH 配置、密码/密钥，不修改网络、代理或服务设置。真实 TUN 验证按用户要求暂缓。

## 已完成的实机检查

### OpenSSH

管理员命令 `--verify-ssh` 分别启动本机 Windows OpenSSH 客户端连接 IPv4 / IPv6 随机非标准端口。客户端使用 `-F NUL`，禁用代理命令/跳板、agent、身份文件和交互认证，不读写用户 known_hosts。测试端只提供合成 SSH banner，并接收有界客户端标识/KEX 数据，不认证登录、不接触真实服务器；探测不记录内容。

修正前，SSH 下行缺失而应用总量正确。匿名端点对照证明经典 TCP 接收事件应保持所属连接的本地/远端排列，修正后：

| 场景 | 连接数 | 测试端送达：客户端接收 / 发送 | SSH 账本接收 / 发送 | 结果 |
|---|---:|---:|---:|---|
| OpenSSH IPv4，非标准端口 | 1 | 30 / 1465 B | 30 / 1465 B | 通过 |
| OpenSSH IPv6，非标准端口 | 1 | 30 / 1465 B | 30 / 1465 B | 通过 |

均为新建出站连接的客户端候选；零已知丢失、零拒收、无身份失效。将合成 SSH 结果写入临时 SQLite，重新打开并重放同批次，报表仍与送达量一致。临时数据库及仅由本命令创建的进程/监听器均释放。原始报告保留在忽略目录，不提交。

此验收不代表真实远端认证/SCP/SFTP 文件传输、Xshell/PuTTY、跳板、ProxyCommand、端口转发、真实 PID 复用、所有 Windows 版本或长运行已验收。候选识别不是协议确认。合成测试覆盖多会话、同元组重连、PID 生命周期、规则别名和容量溢出。

### SQLite

`--verify-history` 创建自有临时数据库，先提交合成事实，再启动本命令的辅助子进程，在已写入但未提交事务内等待。父进程只终止这一准确子进程。重开后，已提交事实保持、相同批次重放只计一次、未提交内容不存在，`PRAGMA integrity_check = ok`。实际原生版本为 SQLite 3.53.4，整个验证通过，临时文件清理。

单元测试另覆盖整批回滚、冲突/陈旧序列拒绝、并发实例幂等、完整 UInt64 范围、较新模式拒绝降级、身份撤回时历史改列未知且原时间/总量不变、零与缺失区分、参数化名称、规则/语言跨重开保存及失败重试。

### 报表与界面

日/周/月、自定义、UTC/选定时区、月边界、DST 23/25 小时日、名称聚合、不同候选身份保留、CSV 引号及公式前缀有自动化覆盖。界面两种语言七页按最小宽度布局并渲染为本地 PNG；复查后修正只读路径绑定、表头语言刷新和 SSH 收发列布局。仅使用合成名称/地址，预览不作为真实流量证明。

报表使用观察结束时间归账，跨期区间不拆分；不是每个字节的精确发生时间。区间质量提示与部分标记不证明全天完整覆盖。窗口采集版本不提供后台服务，关窗期间不记账；SQLite 不补回未提交或未采集流量。长期磁盘容量、自动保留期、升级迁移和 72 小时混合场景仍待验收。
