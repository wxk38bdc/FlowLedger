# 当前支持与验证范围

状态：2026-10-29，开发验证版。下列“通过”仅指注明条件，不是所有 Windows/客户端版本的兼容承诺。

| 能力 | 已完成 | 仍有限制 |
|---|---|---|
| 接口计数、Wi-Fi 候选 | 实时采样、守恒分区、稳定 Wi-Fi 实测 | 实际切换/漫游/睡眠及多出口待验收 |
| ETW TCP/UDP v4/v6 | 管理员受控回环、独立测试实例、方向与类型化同层参考 | 共享内核源；公网重传/卸载及全进程/跨会话覆盖待验收 |
| QUIC | .NET/MsQuic 自定义本机 TLS QUIC，v4/v6 各三轮，按 UDP 事件 size 计量 | 不解析 QUIC 内容；不代表所有浏览器 HTTP/3、公网或应用文件字节 |
| 持续 ETW | 三轮各 30 秒、4 路持续 TCP，零已知丢失/拒收；另 60 秒自然背景资源观察 | 不是最大压力或长期/72 小时稳定性验收；原生主动丢失仍待测 |
| ETW 异常恢复 | 自有会话被中断后 Faulted；自有测试进程被终止后回收一条确实存在的残留，并能启动新会话 | 仅本用户新格式；活跃、不明、旧格式及其他工具/用户会话跳过 |
| Clash API | 当前用户的 CFW 实例：本地认证、端口变化后重新发现、显式代理原应用验证通过 | 未记录/认证任意内核版本；不同客户端能力须单独验收 |
| Mihomo API | 官方 v1.19.33 隔离实例：三轮 HTTP/mixed 回环、401、同端口核心重启 | 仅 DIRECT 本机路径；未启用其 TUN，不替换用户客户端 |
| 代理 TCP 原应用 | API 前后 socket + PID 创建时间证据；HTTP/SOCKS 入站及 TUN 完整四元组规则 | TUN 规则仅合成回归；假 IP/重写/短连接可能未知 |
| 代理 UDP 原应用 | 显示 API 逻辑字节、未知归属 | 尚不确认 UDP 原应用 |
| 去重 | 核心 API 单一计量源，每连接/生命周期/区间一次，链节点不重复加；核心/连接/ETW/接口视图不合计 | 没有整机统一去重总量；活动快照有前段/尾部/短连接缺口 |
| 历史、SSH、后台运行 | 尚未实现 | 关闭丢失用量，暂无日周月报表、SQLite、服务或安装包 |

流量记录在内存中。唯一持久运行辅助文件为本用户 ETW 会话归属标识及桌面合成代理验证的脱敏摘要，不保存控制器密钥或真实连接明细。程序不自动提权，不安装驱动/服务，不更改网络或代理设置。

方法：[ETW 基础实测](validation/2026-10-29-etw-loopback.md)、[本轮可靠性/代理实测](validation/2026-10-29-reliability-proxy.md)、[代理设计](decisions/0004-proxy-accounting.md)。
